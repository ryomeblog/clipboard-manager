# Clipboard Manager

macOS 用のクリップボード履歴アプリ（Electron）。メニューバーに常駐し、⌘ キーを2回押すとカーソル付近に履歴を表示します。

## 機能

- テキストのコピー履歴（ピン留め以外は最大200件）
- 検索
- ピン留め（★）: リストの上に固定され、件数上限やクリアの対象外
- メニューバー（📋）: 履歴を開く / 履歴をクリア / ログイン時に起動 / 終了

## 操作

| キー | 動作 |
| --- | --- |
| ⌘ を2回押す | 履歴を開く/閉じる |
| 文字入力 | 検索 |
| ↑↓（Ctrl+N/P） | 選択を移動 |
| Enter / クリック | クリップボードにコピーして閉じる |
| ⌘1〜⌘9 | n 番目の項目をコピー |
| ⌘P | ピン留めの切り替え |
| ⌘⌫ | 項目を削除 |
| Esc | 検索を消す / 閉じる |

選んだ項目はクリップボードにコピーされ、直前のアプリにフォーカスが戻るので、そのまま ⌘V で貼り付けられます。

## インストール

```sh
npm install
npm run dist
```

`dist/Clipboard Manager-1.0.0-arm64.dmg` を開き、アプリを「アプリケーション」フォルダへドラッグします。

署名していないアプリなので、初回はブロックされます。どちらかの方法で開いてください。

- Finder でアプリを右クリック →「開く」
- または `xattr -cr "/Applications/Clipboard Manager.app"`

### 必要な権限

- **アクセシビリティ**（⌘ の2回押しの検出に使用）:「システム設定 > プライバシーとセキュリティ > アクセシビリティ」で Clipboard Manager を ON にして、アプリを再起動してください。
- **ペーストボード**（macOS 26 以降）: クリップボード読み取りの確認が出たら「許可」してください。

※ アプリを再ビルドすると署名が変わるので、アクセシビリティを一度 OFF→ON し直す必要がある場合があります。

## 開発

```sh
npm start
```

履歴は `~/Library/Application Support/Clipboard Manager/history.json` に保存されます。
